# Autumn Desk — Ход работ

## Цель
Создать автономный веб-проект с интерактивной 3D-сценой «Осенний рабочий стол» на Three.js (локально), с статическим сервером и Makefile, без внешних зависимостей.

## Что сделано

### 1. Структура проекта
- Создана директория `autumn_desk/` с разделением на `public/`, `server.js`, `.env`, `Makefile`, `tests/`
- Скопирована локальная библиотека Three.js r170 из `tree_js/package/` в `public/package/`
- Обновлён путь импорта в `app.js` на `'./package/build/three.module.js'`

### 2. 3D-сцена
- Реализована комната: пол, три стены с тенями
- Дубовый стол с ножками, резной фартуком и декоративными элементами
- Окно с рамой, стёклами (одно створка открыта), видом на осенний пейзаж (деревья, небо) и птицами
- Шторы с анимацией волн
- Ноутбук с экраном Win11 lock screen (CanvasTexture, время, дата, поле пароля)
- Блокнот с текстом на страницах (CanvasTexture)
- Календарь на октябрь 2024
- Декор: кружка, ручка, стопка книг
- 25 падающих листьев с физикой покачивания и вращения

### 3. Интерактивность
- Raycaster/picking: клик по объектам переключает фокус камеры
- 4 интерактивных объекта: окно, ноутбук, блокнот, календарь
- Плавная анимация камеры (ease-in-out cubic) с поддержкой ретаргетинга
- Возврат в home-камеру по клику на фон или Escape
- Курсор меняется на pointer при наведении на интерактивные объекты
- Адаптивная обработка resize и portrait-режима мобильных

### 4. Сервер и управление
- Статический сервер на Node.js с защитой от traversal (`../`) и скрытых файлов
- Makefile с целями `run`, `stop`, `restart`
- PID-файл для управления процессом сервера

### 5. Тесты
- 45 проверок: структура, конфигурация, сервер, сцена, автономность
- Все тесты проходят автоматически через `make test`

## Проблемы и решения

### Проблема 1: Сцена не отображается, ошибок в консоли нет
**Причина:** В функции `animate()` обновлялись все анимации (камера, шторы, листья, птицы), но никогда не вызывался `renderer.render(scene, camera)`. Сцена пересчитывалась, но не отрисовывалась на canvas.
**Решение:** Добавлен вызов `renderer.render(scene, camera)` в конец анимационного цикла.

### Проблема 2: PID не сохраняется, stop|restart не работают
**Причина:** Сервер запускался через `child_process.exec()` без корректной обработки дочернего процесса, PID не записывался в файл.
**Решение:** Запуск через `spawn('node', ['server.js'], { detached: true, stdio: 'ignore' })`, запись PID в файл через `process.stdout.write`, корректная отправка `SIGTERM` через `process.kill(pid, 'SIGTERM')`.

### Проблема 3: Тесты зависали на асинхронных проверках сервера
**Причина:** Использовался старый callback-стиль с `setTimeout`, нет обработки ошибок spawn.
**Решение:** Переписано на async/await, добавлены таймауты, проверка exit-кода, корректное завершение сервера после тестов.
