# Autumn Desk — осенний рабочий стол

Интерактивная 3D-сцена «Осенний рабочий стол» на Three.js/WebGL.

## Запуск

```bash
# Запустить сервер
make run

# Остановить сервер
make stop

# Перезапустить сервер
make restart
```

Сервер запускается на `0.0.0.0:4173` по умолчанию.

Параметры настраиваются через `.env` (скопируйте `.env.example`):

```
HOST=0.0.0.0
PORT=4173
```

## Проверки

```bash
make test
```

## Сцена

- Резной дубовый стол
- Приоткрытое окно с осенним видом и птицами
- Падающие осенние листья
- Шторы с анимацией
- Ноутбук с экраном блокировки Windows 11
- Открытый блокнот с ручкой
- Настольный календарь
- Кофейная чашка, книги, сухой лист

## Интеракции

- Клик по окну, ноутбуку, блокноту или календарю — плавный фокус камеры
- Повторный клик — возврат к общему ракурсу
- Клик по фону или Esc — возврат к общему ракурсу
- Плавный retarget при смене фокуса во время анимации

## Автономность

- Все ресурсы локальные, включая Three.js
- Нет внешних CDN, аналитики, телеметрии
- Ввод с ноутбука хранится только в памяти
