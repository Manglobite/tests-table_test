# RESUME — Autumn Desk

## Что сделано

### Сцена
- Резной дубовый стол с декоративными элементами (резные орнаменты, боковые панели, поперечина)
- Приоткрытое окно с рамой, перемычками, подоконником и стеклянными стёклами
- Осенний вид за окном (небо, силуэты деревьев, земля)
- Анимированные шторы с эффектом складок и покачивания на ветру
- 40 падающих осенних листьев с физикой вращения и дрейфа
- 3 птицы с анимацией крыльев, летящие за окном
- Ноутбук с экраном блокировки Windows 11 (часы, дата, поле пароля, иконка пользователя)
- Открытый блокнот с видимыми страницами, надписями и ручкой
- Настольный календарь с датой (октябрь 2026, день недели)
- Декор: кофейная чашка с ручкой, стопка книг, сухой лист на столе

### Интеракции
- Плавный переход камеры (camera focus) к 4 объектам: окно, ноутбук, блокнот, календарь
- Возврат home повторным кликом на тот же объект
- Возврат home кликом по фону или клавишей Esc
- Плавный retarget при смене фокуса во время анимации
- Picking по объектам сцены через Raycaster

### Сервер
- Python HTTP сервер с безопасной раздачей только публичных файлов
- Защита от traversal-путей, скрытых файлов, symlink-выходов
- Настройка HOST и PORT через .env
- PID-файл для управления процессом
- Корректная обработка MIME-типов

### Адаптивность
- Обработка resize окна
- Поддержка touch-событий
- Мобильный viewport meta

## Автоматические проверки

1. Старт/остановка/повторный старт сервера
2. Разрешённые публичные файлы (index.html, main.js, styles.css, three.module.js)
3. Безопасность: traversal, encoded traversal, hidden files, nonexistent files
4. Автономность: нет CDN, Three.js из локального vendor
5. Интерактивные объекты: window, laptop, notebook, calendar
6. Камера: focusPos, focusTarget, lerpVectors, returnHome
7. Конфигурация: невалидный порт, порт вне диапазона, невалидный хост

## Ограничения

- Визуальная проверка рендеринга выполняется вручную на этапе приёмки
- Нет открытия/закрытия окна, перелистывания страниц календаря/блокнота
- Нет кнопок управления аудио
- Нет localStorage/sessionStorage/cookies
- Экран блокировки ноутбука демонстрационный, без функциональной валидации пароля
