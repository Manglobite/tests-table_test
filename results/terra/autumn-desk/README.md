# Осенний рабочий стол

Автономная Three.js/WebGL-сцена без внешних ресурсов. Локальная копия Three.js находится в `public/vendor/` и раздаётся только как публичный файл.

## Запуск

```bash
cp .env.example .env
make run
```

По умолчанию сервер слушает `0.0.0.0:4173`. В `.env` можно задать допустимые `HOST` и `PORT`. Остановка и перезапуск:

```bash
make stop
make restart
```

Сервер раздаёт только каталог `public`, без листинга каталогов и доступа к скрытым или служебным файлам.

## Управление

Нажмите или коснитесь окна, ноутбука, блокнота либо календаря, чтобы плавно сфокусировать камеру. Повторное нажатие на выбранный предмет, нажатие на фон или `Esc` возвращает общий ракурс.

## Проверки

```bash
make test
```

Проверяются разрешённые публичные файлы, MIME-типы и блокировка скрытых, служебных и traversal-путей. Визуальный WebGL-рендеринг требуется проверить вручную в браузере.
