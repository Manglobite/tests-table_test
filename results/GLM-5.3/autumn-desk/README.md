# Осенний рабочий стол

Самостоятельный офлайн-веб-проект: интерактивная 3D-сцена уютного рабочего
стола ранней солнечной осенью (Three.js r170, локальная копия библиотеки,
без внешних ресурсов и сборки).

## Быстрый старт

```sh
cp .env.example .env   # необязательно: есть значения по умолчанию
make run               # http://localhost:8137
make stop              # остановить сервер этого проекта
make restart           # безопасный перезапуск
make status            # запущен ли сервер
```

Требуется Node.js >= 18. Зависимостей нет. Параметры — в `.env`:

| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `HOST`    | `0.0.0.0`    | адрес сервера (доступ из локальной сети) |
| `PORT`    | `8137`       | порт (1024..65535) |

Сервер (`server.mjs`) отдаёт **только** каталог `public/`: без листинга,
с защитой от traversal (включая %-кодирование), скрытых файлов, симлинков
за пределы корня и методов кроме GET/HEAD. `.env` и исходники проверок
находятся вне публичного корня и не раздаются.

## Управление в сцене

- Клик/тап по **окну, ноутбуку, блокноту или календарю** — плавный фокус камеры.
- Повторный клик по тому же объекту, клик по фону или `Esc` — возврат к общему ракурсу.
- Выбор другого объекта во время перехода — плавное перенацеливание без скачка.
- Экран ноутбука — демонстрационный экран блокировки в стиле Windows 11:
  крупные часы/дата, поле пароля. Ввод живёт только в памяти текущей вкладки,
  никуда не отправляется и не сохраняется.
- Портретный телефон: кадр автоматически ужимается так, чтобы предметы
  оставались в поле зрения.

## Проверки

```sh
make check               # всё сразу
make check-static        # автономность/приватность (внешние URL, хранилища, целостность Three.js)
make check-server        # старт/стоп/рестарт, HOST/PORT, traversal, MIME, симлинки
make check-interactions  # состояния фокуса, плавность retarget, портретная адаптация, picking
```

Проверки не стартуют постоянный сервер (кроме собственного тестового
процесса, который они сами останавливают).

## Структура

```
server.mjs            статический сервер (только public/)
scripts/launch.mjs    run/stop/restart/status с pid-файлом в run/
scripts/check-*.mjs   автоматические проверки
public/index.html     точка входа страницы
public/css/main.css   стили оверлеев (ошибка WebGL, подпись, поле пароля)
public/vendor/        three.module.js — байт-в-байт копия ../tree_js/package/build/three.module.js
public/js/main.js     жизненный цикл: WebGL-проверка, ввод, resize, цикл рендера, dispose
public/js/scene.js    сборка комнаты, света, предметов
public/js/config.js   палитра, размеры, пресеты камеры
public/js/materials.js процедурные canvas-текстуры (никаких внешних файлов)
public/js/camera-rig.js плавные переходы камеры и адаптация под аспект
public/js/interactions.js машина состояний фокуса (расширяемая: register(id, hooks))
public/js/picking.js  raycast hit-testing
public/js/ui.js       оверлеи: WebGL-ошибка, подпись ракурса, поле пароля
public/js/objects/    desk, window, curtains, birds, leaves, laptop, notebook, calendar, decor
```

## Приватность и автономность

- Ноль сетевых запросов в рантайме: все текстуры генерируются canvas-ом,
  Three.js и стили лежат локально.
- Нет `localStorage`/`sessionStorage`/cookie/IndexedDB/телеметрии;
  демонстрационный пароль — только переменная в памяти вкладки, не логируется.
- При отсутствии WebGL показывается понятное сообщение вместо пустого экрана.

## Заметки по приёмке

- Автопроверки: `make check` (сервер, статика, интеракции).
- Рендеринг WebGL и композиция проверяются вручную в браузере: desktop и
  мобильный портрет (инструкция — выше в «Управление»).
