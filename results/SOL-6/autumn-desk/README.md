# Осенний рабочий стол

Автономная WebGL-сцена с локальной копией `tree_js/package/build/three.module.js`; исходная библиотека и референс не изменены. Нужны Python 3.10+, браузер с WebGL. Node.js нужен только для проверки логики камеры.

Из корня этого проекта: `cp .env.example .env` (необязательно), `make run`; затем откройте `http://localhost:8765` на этом компьютере или `http://<локальный-IP-компьютера>:8765` с телефона в той же сети. По умолчанию сервер слушает `HOST=0.0.0.0`, `PORT=8765`; можно изменить оба значения в `.env` (HOST — IPv4). `make stop` останавливает только собственный сервер, `make restart` перезапускает его, `make test` запускает автоматические проверки. Дата на экране и календаре декоративная — 1 октября; пароль не проверяется, не сохраняется и не отправляется.

Кликните или коснитесь окна, ноутбука, блокнота либо календаря для плавного приближения. Повторное касание, клик по фону или Escape возвращают общий ракурс. Для проверки вручную откройте desktop и mobile portrait: проверьте видимость всех объектов, птиц, движение штор и листьев, работу четырёх фокусов, поворот экрана, отсутствие ошибок консоли/запросов и уведомление при отключённом WebGL.
