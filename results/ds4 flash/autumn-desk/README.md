# Autumn Desk — интерактивная 3D-сцена «Осенний рабочий стол»

Самостоятельный веб-проект: резной дубовый стол у приоткрытого окна с осенним
видом, птицами, листьями и мягкими шторами; на столе — ноутбук с экраном
блокировки в стиле Windows 11, открытый блокнот, отрывной календарь и декор.
Всё построено на локальной сборке Three.js, работает полностью офлайн и не
сохраняет пользовательский ввод.

## Требования

- Python 3.8+ (только стандартная библиотека) — для статического сервера и тестов.
- Node.js 18+ — только для JS-тестов и проверки синтаксиса (в рантайме не нужен).
- Проект не тянет зависимости из сети: локальная библиотека уже лежит в
  `public/vendor/three/three.module.js` (точная копия
  `../tree_js/package/build/three.module.js`, Three.js r170).

## Быстрый старт

```bash
cp .env.example .env     # при необходимости отредактируйте HOST/PORT
make run                 # запустить сервер
# откройте http://<HOST>:<PORT>/  (по умолчанию 0.0.0.0:8173)
make stop                # остановить
make restart             # перезапустить
make status              # проверить состояние
```

`make run` печатает адрес и PID. Сервер слушает `HOST` из `.env`
(`0.0.0.0` — доступ в локальной сети, удобно открыть с телефона).

## Управление сервером

| Команда | Действие |
|---------|----------|
| `make run` | запускает статический сервер (только этот проект) |
| `make stop` | останавливает процесс, записанный в `var/server.pid` |
| `make restart` | `stop` + `run` |
| `make status` | показывает, запущен ли сервер проекта |
| `make check` | валидация конфигурации, наличие библиотеки, синтаксис JS |
| `make test` | все автотесты (сервер + privacy + камера + сцена) |
| `make clean` | удаляет pid/log/lock-артефакты |

Менеджер процессов (`server/manage.sh`) никогда не использует `pkill`,
`killall` или завершение по имени/порту. Перед остановкой он сверяет
`/proc/<pid>/cmdline` с путём нашего `serve.py`, поэтому чужой процесс с
переиспользованным PID не пострадает. Занятый порт — понятная ошибка без
вмешательства в чужой сервер.

## Конфигурация `.env`

```dotenv
HOST=0.0.0.0     # адрес прослушивания
PORT=8173        # свободный порт >= 1024
PUBLIC_DIR=public
```

Все значения проверяются до старта: некорректные `HOST`/`PORT` (пустые,
нечисловые, вне диапазона, привилегированные порты) дают ясное сообщение и
код возврата 2. Приоритет: аргументы CLI → переменные окружения → `.env`.

## Что отдаёт сервер

`server/serve.py` отдаёт **только файлы из `PUBLIC_DIR`**:

- запрещены обходы каталога (`..`, в т.ч. в percent-кодировке), обратные слэши,
  NUL-байты, управляющие символы;
- запрещены скрытые файлы и каталоги (`.env`, `.git` и т.п.);
- симлинк, ведущий за пределы публичного корня, не отдаётся (проверка через
  `realpath` + `commonpath`);
- нет листинга каталогов и записи; разрешены только `GET`/`HEAD`;
- неизвестные расширения не отдаются; MIME-типы — из белого списка;
- выставляются `X-Content-Type-Options: nosniff`, CSP, `Referrer-Policy`,
  `X-Frame-Options: DENY`, `Cross-Origin-Resource-Policy`.

## Интерактивность

- **Клик/тап по объекту** — плавный перелёт камеры к окну, ноутбуку, блокноту
  или календарю. Выбор идёт настоящим `Raycaster`-ом по геометрии сцены
  (`userData.focusId`), а не по экранным координатам.
- **Повторный клик по тому же объекту**, клик по фону или `Esc` — возврат к
  общему виду (home).
- **Выбор другого объекта во время перелёта** — плавное перенацеливание без
  рывка (экспоненциальное демпфирование, кадронезависимое).
- **Ноутбук в фокусе** — на экране блокировка Windows 11 и поле ввода пароля.
  Ввод демонстрационный: наружу уходит только *длина* строки, символы не
  журналируются, не сохраняются и не отправляются.
- Мышь: перетаскивание — орбита, колесо — зум. Сенсор: один палец — орбита,
  два — масштаб. После ручного управления камера «принимает» текущий ракурс,
  поэтому орбита и автофокус не конфликтуют.

## Камера и адаптивность

- На широком экране — настольный ракурс, видны все ключевые предметы.
- В портретной ориентации телефона кадр автоматически отдаляется по аспекту,
  камера отходит, FOV расширяется; элементы UI переезжают вниз.
- `resize`/`orientationchange` пересчитывают размеры, pixel ratio и позы без
  растяжения и обрезки.

## Автономность и приватность

- Нет внешних URL: все текстуры генерируются на `<canvas>` в рантайме.
- Нет `fetch`/XHR/WebSocket/`sendBeacon`, нет `localStorage`/`sessionStorage`/
  cookies/IndexedDB и динамических `import()` — это проверяется тестами.
- Точка входа библиотеки — единственный модуль `js/core/three-import.js`,
  импортирующий локальный `public/vendor/three/three.module.js`.

```

├─ .env.example             # HOST/PORT/PUBLIC_DIR
├─ server/
│  ├─ serve.py              # безопасный статический сервер
│  └─ manage.sh             # управление процессом (PID-scoped)
├─ public/
│  ├─ index.html
│  ├─ styles/app.css
│  ├─ vendor/three/three.module.js
│  └─ js/
│     ├─ main.js            # точка входа и жизненный цикл
│     ├─ core/              # фокус камеры, адаптивность, импорт Three.js

   └─ python/               # сервер, безопасность, privacy, жизненный цикл
```

## Тесты

```bash
make check        # быстрые статические проверки (сервер не запускается)
make test         # всё: unit-тесты камеры, интеракций, сцена, сервер, privacy
```

Что покрыто автоматически:

1. старт/останов/повторный старт, изоляция чужого процесса, занятый порт,
   отказ при некорректных `HOST`/`PORT`;
2. отдача разрешённых файлов и MIME, отказ на traversal (включая кодированные),
   backslash/NUL, dotfiles, симлинк-выход, отсутствие листинга, запрет записи;
3. офлайн-поставка: локальный импорт Three.js, отсутствие сетевых API и
   хранилищ, совпадение vendor-копии с исходной библиотекой;
4. фокус на всех четырёх объектах, все пути возврата home, плавный retarget;
5. сборка всей сцены с обязательными предметами и hit-таргетами (без браузера).

## Ограничения

- Автотесты не запускают настоящий WebGL: реальный рендеринг, читаемость
  композиции и поведение на устройстве проверяются вручную в браузере
  (desktop и узкий mobile portrait).
- Сцены-заглушки для WebGL-рендеринга в CI нет намеренно — не добавляем
  headless-браузер как зависимость.
