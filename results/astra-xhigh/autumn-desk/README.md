# Тихий сентябрь

Самостоятельная процедурная Three.js-сцена без npm-зависимостей и сетевых ресурсов. Требуются Python 3.10+, Make и браузер с WebGL 2. Node.js 20+ нужен только для автоматических проверок.

## Запуск

Из каталога `autumn-desk`:

```sh
make run
make stop
make restart
```

Настройки находятся в `.env`; образец — `.env.example`. По умолчанию `HOST=0.0.0.0`, `PORT=8841`. Порт 8841 был свободен при подготовке. Открыть `http://localhost:8841` или `http://<host-ip>:8841` из локальной сети, если адрес хоста не изменился. Доступ через LAN зависит также от настроек firewall.

`HOST` допускает IPv4 или `localhost`, `PORT` — целое 1024–65535. Переменные оболочки не перекрывают `.env`. Повторный `run` не создаёт второй процесс. `stop` использует приватный Unix-сокет и случайный токен, а не PID, имя процесса или порт. Служебные файлы и журнал ошибок находятся в `.runtime/`; HTTP-запросы не журналируются. `restart` проверяет конфигурацию до остановки.

## Управление

Клик или короткое касание окна, ноутбука, блокнота либо календаря плавно фокусирует камеру. Повторное нажатие того же объекта, фон или Escape возвращают общий вид. Другой объект можно выбрать во время перехода. Шторы, листья и птицы движутся; настройка системы reduced motion останавливает декоративную анимацию.

Экран ноутбука — демонстрационная текстура с часами, датой и изображением поля пароля. Поле намеренно не редактируется: базовая интеракция ограничена фокусом камеры. Ввод, авторизация, сохранение и передача пользовательских данных отсутствуют. Дата композиции фиксирована: 21 сентября 2026 года.

## Структура и автономность

- `public/js/main.js` — WebGL, жизненный цикл, размер и освобождение ресурсов.
- `world.js`, `textures.js` — пространственные объекты, процедурные текстуры, анимация.
- `focus.js` — независимые состояния и плавное движение камеры.
- `picking.js` — геометрический Raycaster, pointer events и Escape.
- `server.py` — только публичная раздача и управление процессом.

Браузер импортирует `/tree_js/package/build/three.module.js` из публичного каталога: это побайтовая копия предоставленного `../tree_js/package/build/three.module.js` r170, с сохранённой лицензией в заголовке. Оригинальная библиотека и референс не изменяются. Копия нужна, чтобы сервер не раздавал файлы за пределами `public`; проект можно переносить целиком без родительской директории. Все остальные ресурсы генерируются локально. CSP запрещает исходящие соединения, формы и внешние ресурсы.

## Проверки

```sh
make check
make test
```

`check`: синтаксис Python/JavaScript, локальные импорты, побайтовая идентичность Three.js, статические проверки приватности. Проверка идентичности требует исходный соседний каталог `tree_js`; это не зависимость запуска.

`test`: дополнительно состояние камеры, непрерывность retarget, портретное кадрирование, настоящий Three.js Raycaster через pointer handlers, фон, повторный выбор, Escape и снятие обработчиков; серверный жизненный цикл, настройки, занятый порт, чужой процесс, MIME, traversal, кодирование и симлинки. Серверные тесты запускают только временные тестовые экземпляры на свободных loopback-портах, удаляют их и тестовые каталоги. Обычный сервер проекта автоматически при проверках не запускается. Отдельных установленных линтеров/TypeScript нет: используются встроенные синтаксические проверки и тесты.

## Ручная приёмка

Браузерная/визуальная проверка исполнителем не выполнялась: браузера в окружении нет.

1. Открыть страницу на desktop (например, 1440×900): проверить дубовый стол и резьбу, окно, деревья, птиц, шторы, ноутбук справа, блокнот спереди и календарь слева.
2. Проверить мягкие тени, движение листьев/штор, читаемость каждой текстуры в фокусе. Все четыре объекта должны быть доступны без перекрытия.
3. Нажать каждый объект, повторить нажатие, нажать фон, Escape. Во время движения выбрать другой объект: скачков быть не должно.
4. Проверить на реальном телефоне и в портретных размерах 390×844 и 360×640: полный стол в home, выбор пальцем, читаемость при фокусе. Изменить размеры окна во время фокуса.
5. Проверить Console и Network: отсутствие ошибок, все запросы только к локальному серверу. Отключить внешнюю сеть и перезагрузить при доступном локальном сервере.
6. Проверить сообщение без WebGL 2, восстановление графического контекста, уход со страницы и возврат, настройку reduced motion.

Производительность, фактическая читаемость и визуальное качество WebGL требуют этой ручной проверки. Автоматические проверки не заменяют рендеринг на GPU.
