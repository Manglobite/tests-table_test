# Autumn Desk — сравнительный бенчмарк

Набор независимых решений одной задачи: интерактивная 3D-сцена «Осенний
рабочий стол» на Three.js/WebGL, выполненная разными моделями.

## Состав

- `test/task.md` — текст задания для исполнителя.
- `test/refs/sakuragaoka-station` — сторонний референс (не изменялся).
- `test/tree_js` — локальная библиотека Three.js r170, предоставленная заданием.
- `results/<модель>/` — результаты прогонов:
  - `autumn-desk/` — самостоятельный проект решения (сервер, `public/`, Makefile, README, RESUME);
  - `tree_js/` — локальная копия библиотеки (не публикуется, см. `.gitignore`);
  - `*_table_test.md` — полный лог работы модели над заданием (бенчмарк).
- `commands.md` — стартовые условия прогона.

## Изоляция прогонов

Задание рассчитано на независимое «слепое» выполнение. Два прогона Qwen 3.6 35B A3B
потребовали отдельного пояснения:

- `results/qwen3.6_35B_A3B/` — прогон, в котором модель нарушила границы изоляции
  и подсмотрела материалы соседнего решения (`results/terra`). Факт зафиксирован в
  `notes.md` и в логе прогона. Результат сохранён для истории.
- `results/qwen3.6_35B_A3B_by_agent/` — контрольный перепрогон той же модели в
  изолированном окружении: стартовые условия и жёсткие ограничения доступа
  заданы агентом `test/.opencode/agent/autumn-desk-builder.md` (запрет на всё
  вне рабочего каталога, сеть, сабагентов и интерактивные запросы). Сохранён как
  артефакт прогона без нормализации.

## Запуск отдельного решения

Каждый проект запускается автономно из своего каталога `autumn-desk`
(подробности — в его `README.md`). Агент Build Opencode 1.18.18.
У всех решений внутри `public/` есть собственная побайтовая копия Three.js, 
поэтому наличие соседнего `tree_js` для запуска не требуется.

## Ограничения публикации

При подготовке к публикации удалены: карта сетевых сервисов и список процессов
хоста из логов прогонов (которые сделали GLM5.3 и Astra), локальные сетевые адреса 
и пути, серверные логи, pid/lock-файлы и архивы.
Каталоги `tree_js` исключены через `.gitignore`.
